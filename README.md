# 🥗 Plan de Rendimiento y Nutrición

Un diseño web moderno, *mobile-first* y altamente responsivo, creado para organizar y visualizar una estrategia clínica de nutrición y entrenamiento de doble impacto. 

El objetivo principal de este proyecto es transformar información médica y deportiva compleja (macros, suplementación ergogénica, distribución de cargas) en una interfaz rápida, escaneable y atractiva para su uso diario desde dispositivos móviles en el gimnasio o en movimiento.

## ✨ Características
* **Mobile-First Design:** Optimizado para lectura rápida en pantallas pequeñas, pero completamente responsivo en escritorio.
* **Navegación Sticky:** Menú de acceso rápido con soporte de desplazamiento horizontal y efecto de desenfoque (*glassmorphism*).
* **Estética de Alto Rendimiento:** Tema oscuro premium ("Dark Mode") con acentos de color neón para categorizar la intensidad del entrenamiento y los tipos de suplementos.
* **Componentización UI:** Uso intensivo de Flexbox y CSS Grid para organizar la información en tarjetas (*cards*) y comparativas visuales (Diana vs Mati).

## 🚀 Tecnologías
* **HTML5:** Estructura semántica sin dependencias externas.
* **CSS3 Vanilla:** Variables nativas, efectos avanzados (backdrop-filter) y *scroll-behavior* nativo sin necesidad de JavaScript ni librerías adicionales.

## 🎯 Caso de uso
El plan contempla variables críticas para deportistas, tales como la resaturación de ATP mediante suplementación, la deshidratación/hidratación clínica de los alimentos en cocción y el control de cortisol post-entrenamiento para perfiles de Boxeo y Calistenia.
